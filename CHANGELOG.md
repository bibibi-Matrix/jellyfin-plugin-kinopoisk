# Changelog

## [10.11.11.8]

- Миниатюры эпизодов из данных КиноПоиска (алгоритм KinopoiskDev)
- Логотип и обложка фильма в галерее изображений (алгоритм Unofficial, поля logoUrl/coverUrl)
- Скриншоты как Thumb-превью (KinopoiskDev)
- Статус сериала из поля источника (ongoing/completed) с приоритетом над эвристикой по датам
- Премьера: приоритет российской даты над мировой
- Студии-производители в карточке (KinopoiskDev)

## [10.11.11.7]

Исправлены эндпоинты алгоритма KinopoiskDev по актуальной спецификации API: поиск (/v1.4/movie/search), сезоны с эпизодами (/v1.4/season), галерея изображений (/v1.4/image, до 250 шт.)

## [10.11.11.6]

- Выбор алгоритма доступа к КиноПоиску в настройках плагина
- Новый алгоритм KinopoiskDev (kinopoisk.dev): постеры, баннеры, люди, трейлеры, эпизоды и премьеры через единый бесплатный токен
- Настройка: переключение бэкенда + отдельный токен для каждого алгоритма

## [10.11.11.5]

- Точная дата премьеры из данных проката/дистрибуции (вместо "1 января года")
- Статус сериала (продолжается/завершён) и даты начала/конца по датам эпизодов
- Названия, описания и даты эпизодов сериалов
- Интересные факты о фильме в конце описания (без спойлеров, до 3 шт.)
- Кадры из фильма в галерею изображений (дополнительно к баннерам)

## [10.11.11.4]

- Возрастной рейтинг: убран лишний префикс "age" ("age16+" -> "16+"), MPAA приведён к верхнему регистру
- Хронометраж: парсинг формата "HH:mm", который возвращает API (раньше поле терялось)
- Описание: если полного описания нет, используется краткое; HTML-теги вычищаются
- Фильтр по типу контента: метаданные фильма не применяются к сериалу и наоборот (FILM/VIDEO против TV_SERIES/MINI_SERIES/TV_SHOW)

## [10.11.11.3]

Загрузка длинных баннеров (задников) из галереи КиноПоиска - до 20 кадров на фильм, прямые URL без редиректов

## [10.11.11.2]

Исправлена деградация загрузки изображений при сбоях DNS/сети в контейнере: ретраи при временных ошибках сети и возврат исходного URL вместо отбрасывания изображения (по логам сервера: SocketException EAGAIN на st.kp.yandex.net)

## [10.11.11.1]

Исправлена загрузка постеров: устойчивость к редиректам антибота КиноПоиска, запасной вариант через preview-постер, ошибки API (лимит квоты) больше не ломают провайдер изображений целиком
